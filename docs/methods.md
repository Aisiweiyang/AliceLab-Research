# 方法与证据边界

## 变点检测

使用 Normal–Inverse-Gamma 共轭分段边际似然，单断点位置后验与离线多断点动态规划。多断点结果只在 `0..k_max` 支持上归一化，段长采用几何权重并受 `min_seg` 限制；后验依赖先验、尺度和分段上限。不能把它当作对任意真实市场机制数的已校准概率。

参考方法出处：Kevin P. Murphy, *Conjugate Bayesian analysis of the Gaussian distribution* (2007)；Paul Fearnhead, *Exact and efficient Bayesian inference for multiple changepoint problems* (2006)。代码由原 AliceLab 的 NumPy 实现整理，不捆绑第三方检测包源码。

算法使用整段数据，属于离线诊断。滚动应用需要另行定义仅使用当时已知信息的协议。CUSUM 辅助函数不自动标准化，漂移参数由调用者在相同尺度上设定。

## 事件研究的修正

原内部工具把数百日残差均值的抽样分布与单日异常收益比较，两者统计量尺度不同。本公开版移除了这条推断路径，也未发布依赖旧 p 值的报告。

当前流程：在事前估计窗拟合带截距市场模型；估计窗残差去均值；对每个 CAR 长度 h 构造同为 h 会话的连续残差和；有放回抽样作为经验参照；双侧尾部概率采用 `(1 + exceedances)/(B + 1)`，不会输出零 p 值。

连续窗口保留窗口内的部分时间依赖，但重叠窗口并不独立，更多抽样不能弥补独立历史样本不足。方法未完整建模 alpha/beta 估计不确定性、事件诱发波动、异方差或多重检验；经验 p 值不等同于严格校准的统计检验。同期事件、复权、时间戳和样本选择需独立审查。

## 能力—价格分析

- 前沿：更低或相等价格、更高或相等能力，至少一维严格改善；完全重复点保留。
- 达标价：每月所有能力达到阈值模型的最低价；合格集合为空时输出缺失。
- 构成分解：总几何均价的对数变化减去连续两月存活模型的平均对数价格变化，得到残差。残差包含净进入/退出与权重变化，不能命名为“开源冲击的因果效应”。
- Hedonic：月内 OLS `log(price) ~ intercept + log(capability)`，输出固定参考能力的预测价格；样本与函数形式约束很强，不自动给出可靠置信区间。
- 跨版本链接函数提供比率诊断，不证明基准具备比例可比性，CLI 默认拒绝混合版本。
