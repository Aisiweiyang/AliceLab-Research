# 开源整理范围

公开仓库采用新 Git 历史，未把私有仓库改为公开。原始工作区及私有历史留作本地恢复来源。

保留并适配：离线变点检测与原回归测试、CUSUM、价格—能力前沿、达标价与构成分解、hedonic 计算、事件研究和输入清单。三类研究配方共享同一个执行器。

未纳入公开版本：

- 旧 Alice v4/v5 量化框架及其入口、行情数据库引用；
- 个人 `research_data`、虚拟环境、缓存和独立嵌套仓库；
- 历史行情 CSV、供应商网页快照、第三方能力与价格面板；
- 已作废实验、调试探针、生成图片、HTML 看板、内部论文和项目治理记录；
- 依赖原数据库的回测、特定历史事件估计和未完成研究方向；
- 与当前运行范围无关的数据采集、爬取和文档生成依赖。

上述内容保留在本地归档，不进入公开仓库或 Git 历史。数据整理并未证明第三方资料具有可再分发权，因此公开版仅生成原创合成数据。将来引入真实数据前，应单独明确来源、许可、版本和核验范围。

这是一版范围明确的研究工具提取，不声称原私有平台的全部功能已迁移。
